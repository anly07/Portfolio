Common Questions

FAQ

Answers to what recruiters and collaborators usually ask first.

What kind of projects do you specialise in?

I specialise in real-time IoT and industrial dashboards interfaces where live sensor data needs to be clear, fast, and reliable. I also build responsive landing pages and SEO-optimised websites. My workflow always starts with a Figma prototype so clients see exactly what they're getting before a line of code is written.

What's your design-to-development process?

I start with a discovery session to understand the client's data and goals. Then I build a Figma prototype wireframes first, then high-fidelity mockups with the correct colour system, typography, and component layout. Once the client approves the design, I move to ReactJS development using Bootstrap for responsive structure. This prevents costly rework and keeps both parties aligned throughout.

Are you open to remote or freelance work?

Yes I'm open to full-time roles, contract work, and freelance projects. I'm comfortable working remotely and have experience collaborating across time zones. If you have a dashboard, web app, or design project in mind, feel free to send me an email directly.

You've published ML research does that mean you do data science too?

My primary focus is frontend development, but I have a genuine interest in machine learning reflected in my two published research papers on food recommendation (K-Means + Random Forest) and credit card fraud detection. I can read and understand data pipelines, collaborate with data engineers, and translate complex datasets into clear frontend visualisations. I'm not a data scientist, but I'm not intimidated by data either.

What tools and technologies do you use day-to-day?

My daily stack includes ReactJS, Bootstrap, HTML5, CSS3, and JavaScript (ES6+) for building interfaces. I use Figma for all design and prototyping work, Git for version control, and Google Analytics for performance monitoring and SEO insights. I'm also comfortable with SQL for data querying when needed.

How quickly can you get started on a new project?

I'm currently available for new opportunities. For freelance or contract projects, I can typically begin within a week of scoping and agreement. For full-time roles, timeline depends on notice period best to reach out directly so we can discuss specifics.
